## Pool, mappings and direct I/O

`cli.py:180` actually defaults chunk-size to **32MB**, not 64MiB. Existing `--chunk-size 64MB` is sufficient: `utils.py:192-240` parses MB as 1024**2. No new flag is needed. `PinnedMemoryPool` eagerly aligned_allocs and cudaHostRegisters every chunk during construction. A 640GiB pool is 687194767360 bytes and 10240 registrations at 64MiB (versus 20480 at 32MiB). Registration count is not proven VMA count. Current observed vm.max_map_count=65530 is context, not a capacity proof; record actual per-owned-process maps count, VmRSS/VmPin/VmLck, RLIMIT_MEMLOCK, host counters and cgroup anon/file/unevictable. Do not change sysctls or malloc policy preemptively.

Actual rank archive physical size is 77125095424 bytes. At 64MiB, each rank needs 1150 chunks = 77175193600 bytes; eight need 617401548800 bytes, leaving 69793218560 bytes of this pool. Registration failure is fatal. LRU eviction/FreeHost only return buffers to this already allocated pool; they do not shrink/unpin it. Pool unregister/free occurs when the server is destroyed. No async CPU-load response is proof of completed preload: server CPU confirm is unimplemented, while GPU confirmation proves the load path. Do not add a second giant preload solely for readiness.

`checkpoint_store.cpp:32-83` creates CUDA contexts/streams on all visible GPUs before the pool. Store-server PID may therefore coexist with a worker PID on each card. All these processes must belong to the same authenticated CID scope; do not require exactly one process per GPU. `server.py:209+` constructs the pool before grpc server.start, so TCP readiness is downstream of pool construction, but startup time for 640GiB registration is not measured by the component test.

`model.cpp:95-104` opens archive parts O_DIRECT|O_RDONLY, but EINVAL explicitly falls back to buffered O_RDONLY. The eventual recipe must collect actual owned-server fd targets and fdinfo flags while parts are open, correlate each actual archive part, and preserve fallback/error logs. Require demonstrated O_DIRECT for the path that excludes an additional full input page-cache charge. A missed fd observation is missing proof, not proof of direct I/O. If a fallback is detected, stop this attempt safely rather than silently spending the omitted cache budget. Never drop shared caches. Bounded representative reference reads may be buffered and must be accounted separately; they are not an O_DIRECT throughput measurement.
